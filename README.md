# NEO BELLSTAR

ツインビー／グラディウス系の **武器強化型シューティング**。
横スクロール、HTML5 Canvas 製。ビルド不要、`index.html` を開けば動く。

![プレイ画面](docs/shot-play.png)

## コンセプト

> **敵はどんどん増える。でも難易度は上がらない。増えた敵はそのまま火力になって返ってくる。**

普通のシューティングは、時間が経つほど敵が硬く・速く・弾も多くなる。
このゲームはそこを逆にした。増やすのは **敵の数（密度）だけ**。
危険の総量は最初から最後まで固定し、伸びるのは自機の火力と気持ちよさだけにしてある。

実測値（`node tools/smoke-test.js` の出力より、ゲーム内 6 分間）:

| 経過 | 湧く敵 | 画面内の敵 | 敵弾の上限 | 自機の火力 |
|---|---|---|---|---|
| 開始直後 | 1.5 匹/秒 | 〜15 | 18 発 | 約 10 DPS |
| 2 分 | 12 匹/秒 | 〜60 | 18 発 | 約 50 DPS |
| 5 分 | 90 匹/秒 | 100〜230 | 18 発 | 約 150 DPS |

敵の量は **約 60 倍**、危険の量は **変わらない**。

## 「難しくならない」を保証している 5 つの仕組み

思想を口で言うだけでは守られないので、コードの仕組みとして入れてある。
値はすべて `js/config.js` に集約してあり、いじれば手触りが変わる。

### 1. 弾幕予算（bullet budget）

画面上に存在できる敵弾の総数に固定の上限（18 発）を設けている。
敵が 5 匹でも 200 匹でも同じ。敵が増えるほど 1 匹あたりの発射確率が自動で下がるので、
「撃たれる量」は最初から最後までほぼ一定になる。

```js
// js/enemies.js
Enemies.canFire = function (G) {
  var n = G.eb.length;
  if (n >= TH.bulletBudget) return false;       // 上限に達したら撃たない
  var ratio = n / TH.bulletBudget;
  if (ratio <= TH.softCapRatio) return true;
  return Math.random() < 1 - (ratio - TH.softCapRatio) / (1 - TH.softCapRatio);
};
```

画面左上の `敵弾 n/18` という表示は、この上限が守られていることを
プレイヤー自身が目で確認できるようにしたもの。

### 2. 体当たりの危険も固定する

弾だけ抑えても、敵が 10 倍に増えれば体当たりの危険が 10 倍になって結局は難しくなる。
そこで敵を 2 種類に分けた。

- **ザコ（HP 2 以下）** … いくら増えても、自機に当たっても自機は壊れない。
  砕けて得点になるだけ。**増やす対象はこちらだけ**。
- **武装敵（HP 3 以上：砲台・ポッド・大型艦）** … 自機を壊しうるが、
  画面内の数に上限（8 体）がある。超える分はザコに差し替えられる。

つまり「敵の総数」は減らさず「危険の量」だけを一定に保っている。

### 3. 敵の性能を一切上げない

HP・弾速（118 px/秒）・狙いのブレ（±0.17 rad）は最後まで固定。
弾速は自機の移動速度より遅いので、原理的に必ず避けられる。
増えるのは数だけで、1 匹を倒すのにかかる時間（TTK: Time To Kill）は
武器が強くなるぶん **むしろ短くなっていく**。

### 4. 撃破数に比例したパワーアップ供給

一定数倒すごとに必ずパワーカプセルが出る。
**敵が増える → 供給が増える → 火力が上がる → もっと倒せる**、という直結を作ってある。
編隊を全滅させたときのカプセル確定（グラディウス方式）も同じ狙い。

ただし供給には時間の上限（最短 0.55 秒に 1 個、画面内 8 個まで）も入れた。
終盤に毎秒 7 個も降ってくるとメーターのカーソルが制御不能になり、
「好きな装備を選ぶ」というグラディウスの遊び自体が壊れてしまうため。

### 5. ミスのペナルティを軽くする

グラディウス方式の「死ぬと全パワー喪失」はやっていない。
失うのはオプション 1 個とシールドだけで、代わりにボムが 1 つ補充される。
全ロストさせると、ミスした瞬間に急激に難しくなる典型的な難易度スパイクが生まれるから。

## 「爽快感が増える」ための仕組み

### チェイン（連鎖）

短時間に倒し続けるほどゲージが伸び、**連射速度が最大 1.8 倍**になり、
30 連鎖・90 連鎖で上下へのサイドショットが自動で追加される。得点倍率も上がる。

敵が多いほど連鎖が途切れない ＝ **敵が多いほど自機が強い**。
密度の上昇が自動的に火力上昇に変換される自己平衡の仕組みになっている。

### 武器の伸び方

| 装備 | 効果 |
|---|---|
| SPEED ×4 | 移動速度 195 → 379 px/秒 |
| MISSILE ×3 | 追尾ミサイル 1 → 4 発同時、威力 3 → 5 |
| DOUBLE ×3 | 2way → 3way → 5way |
| LASER ×3 | 貫通レーザー。3 段で 3 本同時 |
| OPTION ×4 | 自機の軌跡を追う分身。**全弾がそのまま 5 倍になる** |
| FORCE | 5 発ぶん受け止めるバリア |

オプション 4 つ＋レーザー 3 段＋チェイン最大で、初期のおよそ **15 倍**の火力になる。

### 音も強くなる

BGM はレイヤー方式で、装備が増えるほど楽器が増える
（ベース → アルペジオ → ハイハット → リード）。音声ファイルは使わず、
WebAudio のオシレーターで合成している。

### 演出

加算合成のパーティクル、衝撃波リング、画面揺れ、大型撃破時のヒットストップ（一瞬の静止）、
チェインに応じた画面の色づき、パララックス星空。
負荷が上がるとパーティクル量を自動で落とすので、敵が 200 匹出ても操作は重くならない。

## 遊び方

| 操作 | キー |
|---|---|
| 移動 | 方向キー / WASD |
| ショット | Z または Space（押しっぱなしで連射） |
| パワーアップ発動 | X |
| ボム | C |
| 低速移動 | Shift |
| ポーズ | P |
| ミュート | M |
| リスタート | R |

スマホ・タブレットでは画面をドラッグで移動、触れている間は自動連射。

### パワーアップの流れ（グラディウス方式）

1. 赤いカプセル `P` を取ると、画面下のメーターのカーソルが 1 つ進む
2. 欲しいスロットで **X** を押すと発動し、メーターは 0 に戻る
3. `SPEED → MISSILE → DOUBLE → LASER → OPTION → FORCE` の順で、
   奥のスロットほど強力だが、そのぶんカプセルを溜める必要がある

早めに OPTION を取りに行くか、先に SPEED で動きやすくするかは好み。

### ベル（ツインビー方式）

雲を撃つとベルが出る。**ベルを撃つたびに色が変わり、効果も変わる**。

| 色 | 効果 |
|---|---|
| 黄 | 3000 点 |
| 青 | スピードアップ |
| 白 | ショット強化 |
| 緑 | オプション追加 |
| 赤 | バリア |

落ちてくる前に撃ち上げて、欲しい色に合わせてから取る。

```sh

```

- 読み込み時・プレイ中に JS エラーが出ないこと
- **敵弾が予算 18 発を 1 フレームも超えないこと**（設計の根幹の自動テスト）
- 時間経過で敵の密度と自機の火力が実際に増えていること

スクリーンショットは `docs/` に保存される。

## 調整したいときに触る場所

すべて `js/config.js`。

```js
threat.bulletBudget   // 敵弾の上限。ここが難易度の主スイッチ
threat.armoredMax     // 自機を壊しうる敵の同時数
threat.bulletSpeed    // 敵弾の速さ（上げると純粋に難しくなる）
director.countPerWave // 1 編隊あたりの敵の増え方
director.intervalFloor// 編隊の最短間隔（下げるほど画面が埋まる）
director.aliveMax     // 画面内の敵の最大数（処理落ち対策）
chain.rateAt          // 連射が最大になる連鎖数
weapon.optionMax      // オプションの最大数（火力の伸びに直結）
```

「もっと敵で埋め尽くしたい」なら `director.intervalFloor` を下げて
`countMax` と `aliveMax` を上げる。それでも `bulletBudget` と `armoredMax` を
触らない限り、難易度は上がらない。

## 用語

- **DPS** … Damage Per Second。1 秒あたりに与えられるダメージ量。火力の指標
- **TTK** … Time To Kill。敵 1 匹を倒すのにかかる時間
- **弾幕** … 画面を埋める敵弾。本作では意図的に量を制限している
- **オプション（マルチプル）** … 自機の軌跡を追って同じ弾を撃つ分身
- **オブジェクトプール** … 使い回し用に確保しておく配列。
  毎フレーム大量に生成・破棄するとゴミ集め（GC）で一瞬固まるのを防ぐ
- **加算合成（lighter）** … 色を足し算で重ねる描画方式。光が重なるほど白く飛ぶ
- **固定タイムステップ** … 更新を常に 1/60 秒刻みで行う方式。
  フレームレートが揺れても弾速や当たり判定がブレない
